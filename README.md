# 📝 To-Do List

A simple, clean to-do list web app built with **HTML**, **CSS** and **JavaScript**. Add tasks, mark them as done and remove them when you're finished, all in the browser with no installation or dependencies.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks you no longer need
- Lightweight and fast: no frameworks, no build step
- Works in any modern browser

## 🛠️ Built With

| Technology | Purpose |
| ---------- | ------- |
| HTML5      | Page structure |
| CSS3       | Styling and layout |
| JavaScript | App logic and interactivity |

## 🚀 Getting Started

No setup required.

1. **Clone the repository**
   ```bash
   git clone https://github.com/cs-jeeteswar07/To_do_list_basic_project.git
   ```
2. **Open the project folder**
   ```bash
   cd To_do_list_basic_project
   ```
3. **Run it**: open `index.html` in your browser (double-click it, or right-click → *Open with* → your browser).

Optionally, use the **Live Server** extension in VS Code for auto-reload while editing.

## 📖 How to Use

1. Type a task into the input box.
2. Click **Add** (or press **Enter**) to add it to the list.
3. Click a task to mark it as completed.
4. Use the delete button to remove a task.
